Forms:

forms in html are created with form tag to collect data from user. action attribute is used to give file path where these input data will be processed.

input tag is used to read input. Attribute type to know which kind of data will be entered like text. Attribute placeholder is used to show text to guide user.

Labels help user with physical disabilities. we use label tag for it with attribute for and value id.

when we need to select multiple options we use checbox type in input


if you want user to write any feedback, we use textarea tag with attributes as name, id, placeholder, etc.

select tag is used to add dropdown menu with name, id, etc attibutes. Option tag is used with value for options.

input type submit is used to submit form

Iframe tag :

iframe tag is used to show functional websites inside websites.

video tag is used to add videos on websites.
