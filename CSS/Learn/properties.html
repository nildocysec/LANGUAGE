Units:

pixels is absolute units px. Relative units are percentage, em and rem.

Percentage :

This size is relative to parent element for child element. for example div inside div.

em :

for font size relative parent for child element 1em means equal, 2 means double, 0.5em means half etc. for width 1em means equal, 2 means double, 0.5em means half etc of elements own font size.

rem :

font size relative to root element that is html element in rem like em.

REM

vh and vw

1vh, 1vw is relative to 1 percent of viewport that is browser screen's height, width

position property :

Static :

default position that is no effect on top, bottom, left, right, z index property. top/left/right/bottom property means distance of element from top/left/right/bottom of document.

static
relative
absolute
fixed
what!!

relative :

position will change from its initial boundary position.

absolute :

Positioned with respect to closest not static parent element.

fixed :

Positioned relative to document edges like footer at end of document. if we scroll, these element will be always visible and remain fixed in that position.

sticky :

Positioned based on user's scroll behaviour. After scrolling as element is encounted in given position it will become fixed.

Z-index property

When two or more elements overlap by default element written later comes up. These can be decided otherwise wit z-index. Larger the z index, more up it comes in elements stack. Just like top, bottom, left, right, z-index can be negative and positive, positive means move in +ve part of axes while -ve means move in negative part of axes but unitless.
