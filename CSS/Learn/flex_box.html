Flex Box Layout :

It is a one dimensional layout method for arranging items in rows or columns. for any container, we set display property as flex and it becomes flex container. It has two axes at 90 degree angle, main and cross axes.

flex-direction :

Sets how flex items placed in flex container along with axis and direction. All items will fit into container regardless of height and width as long content allows.

By default it is row which means all items have main axis as row and from left to right.

Another is row-reverse which means all items have main axis as row and from right to left.

column which means all itmes have main axis as column and from top to bottom.

column-reverse means all items have main axis as column and from bottom to top.

justify-content :

Similar to text-alignment, this property decides alignment of items in container along main axis.

Value flex-start means start of main axis, flex-end means end of main axis, center means center of main axis. space-around means extra space will be adjusted around items while space-between means extra space will be adjusted between items but space-evenly means extra space will be adjusted between and around items equally.
